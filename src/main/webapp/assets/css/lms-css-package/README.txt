LMS Member Management CSS package

Contents:
  css/member-management.css

Install:
1. Extract this ZIP.
2. Copy css/member-management.css into your project at:
   src/main/webapp/assets/css/member-management.css
   (Use the existing assets/css folder in your project if its location differs.)
3. Replace the existing member-management.css when prompted.
4. Keep the stylesheet linked in members.jsp. Load lms-editorial-theme.css first and member-management.css second.
5. Restart Tomcat and hard-refresh the browser (Ctrl+F5).

This stylesheet is intended for the full-width Member Management pages with the left sidebar removed from the page layout. It does not change Java, JSP logic, database code, or routes.
